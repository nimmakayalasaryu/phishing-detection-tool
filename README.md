# 🔐 AI-Powered Phishing Detection & Email Security Tool

An intelligent cybersecurity tool that detects phishing emails and malicious URLs using AI and threat intelligence APIs.

## 🚀 Features
- AI-based phishing email detection  
- URL malware scanning using VirusTotal  
- Risk scoring and explanation  
- Automated SOC-style security reporting  

## 🧠 Technologies Used
- Python  
- OpenAI API  
- VirusTotal API  
- OSINT  
- Cybersecurity Detection Workflows  

## 🏗️ Project Architecture
User Input → AI Analysis → Threat Intelligence → Risk Scoring → Security Report
